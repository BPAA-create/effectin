💡 Tips Penggunaan: Anda bisa langsung menekan angka 1 hingga 9 di keyboard kapan saja tanpa harus mengklik tombol. Tekan Space atau Esc untuk menghentikan semua suara seketika, dan tekan L untuk toggle Mode Loop. Jika link audio (.mp3) kosong, synthesizer web-audio otomatis berbunyi!

Konfigurasi Suara untuk GitHub

Cara deploy & ubah di GitHub: Simpan file audio Anda di folder sounds/ di repositori GitHub, lalu ganti URL di variabel SOUNDS_CONFIG dalam file index.html.

Dibuat untuk kemudahan hosting di GitHub Pages • Tanpa backend server

Trigger: Numpad 1–9 / Angka 1–9 • Stop: Space/Esc • Loop: L
